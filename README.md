# Scout - Frontend

Next.js frontend for Scout, an autonomous AI research agent.

Live: https://scout-frontend-mauve.vercel.app
Backend: https://github.com/naysar/scout-backend

## Features
- Real-time agent progress via SSE streaming
- Markdown report rendering
- Voice input
- Chat history sidebar
- JWT authentication

## Stack
- Next.js 14
- React
- TypeScript

## Running locally

1. Clone the repo
2. Run npm install
3. Run npm run dev
